# FESPACO - Project Requirements (Laravel)
# NOTE:
# This project is PHP/Laravel (not Python), so dependencies are managed by

# This file is provided as a quick onboarding checklist for collaborators.

[System prerequisites]
- PHP >= 8.2
- Composer >= 2.x
- Node.js >= 20.19 (recommended) + npm
- SQLite (or MySQL/PostgreSQL if configured in .env)

[PHP extensions commonly required by Laravel]

- PDO
- Mbstring
- Tokenizer
- XML
- Ctype
- JSON
- BCMath
- Fileinfo

[Quick setup]
1) Clone repo
2) Install PHP deps:
   composer install
3) Install JS deps:
   npm install
4) Create env file:
   cp .env.example .env
5) Generate app key:
   php artisan key:generate
6) Run migrations:
   php artisan migrate
7) Build assets:
   npm run build

[Development]
- Start full dev stack (server + queue + logs + vite):
  composer run dev
